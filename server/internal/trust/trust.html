Recipes

Trust the recipes on this device

The recipes run on https, which keeps the screen on while you cook and lets timers ring on time. Each device just needs to trust the site's certificate once. It takes about a minute.

Download the certificate
iPhone and iPad
  1. Open this page in Safari, even if you browse in Brave or Chrome, then tap Download the certificate above and Allow. Once it's trusted, every browser on the device trusts it.
  2. Open Settings and tap Profile Downloaded near the top (or find it under General, VPN & Device Management). Tap Install, enter your passcode, and tap Install again.
  3. Still in Settings, go to General, About, then Certificate Trust Settings at the very bottom, and turn on {{.AuthorityName}}.
Mac
  1. Click Download the certificate above, then open the file. Keychain Access adds it.
  2. In Keychain Access, find {{.AuthorityName}} under Certificates and double-click it.
  3. Open Trust and set When using this certificate to Always Trust.
  4. Close the window and enter your password.
Windows
  1. Click Download the certificate above, then open the file and click Install Certificate.
  2. Choose Current User, then Place all certificates in the following store.
  3. Browse to Trusted Root Certification Authorities, finish, and say Yes to the warning.
Linux, in Vivaldi, Chrome, Chromium or Brave
  1. Click Download the certificate above.
  2. In a terminal, install the tool that adds certificates to the browser, if it isn't there yet: sudo apt install libnss3-tools
  3. Add the certificate: certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "{{.AuthorityName}}" -i ~/Downloads/recipes-ca.crt
  4. Quit the browser completely, then open it again.
Android
  1. Tap Download the certificate above.
  2. Open Settings, Security & privacy, More security settings, Encryption & credentials, Install a certificate, then CA certificate.
  3. Pick recipes-ca.crt from your downloads.
Firefox, on a computer
  1. Firefox keeps its own list, so do this as well as the steps for your computer.
  2. Open Settings, Privacy & Security, View Certificates, Authorities, then Import, and pick the file you downloaded.
  3. Check Trust this CA to identify websites.

Then open {{.SecureAddress}}. If it opens without a warning, you're all set. On an iPhone or iPad, add it to your Home Screen from there in Safari (tap Share, then Add to Home Screen), and it will open even away from home.
